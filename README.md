## FONGOING - Plataforma Web Institucional

## Plataforma criada com o foco em gestão de projetos sociais, contratação de voluntários e captação de recursos online para a FONGOING.

## Estrutura do Projeto
- `index.html`: Página Inicial mostrando planos, contatos e funcionários.
- `projetos.html`: Projetos sociais em andamento, métricas de voluntariado e canais de doação on-line.
- `cadastro.html`: Formulário de cadastro de voluntários e doadores com validação nativa, máscaras de input e consulta de CEP via API.
- `css/style.css`: Estilização e layout responsivo do sistema.
- `js/script.js`: Funções de máscaras, validações e consumo da API REST ViaCEP.

## Tecnologias Utilizadas
- HTML5 Semântico: `<header>`, `<main>`, `<section>`, `<article>`, `<fieldset>`, `<legend>`.
- CSS3: Layout flexível, padronização visual e responsividade.
- JavaScript Vanilla: Validação de formulários, máscaras de input (CPF, Telefone, CEP) e integração com a API ViaCEP.
- Acessibilidade: WCAG 2.1 AA com atributos `aria-labelledby`, `aria-hidden` e alt text em todas as imagens.
